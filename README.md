An exploratory data analysis (EDA) project focusing on election candidate demographics, party-level statistics, assets, and criminal case backgrounds.

# Project Highlights
* Data Cleaning:* Processed complex CSV structures with multi-line breaks and converted candidate asset metrics into standardized numerical formats.
* Exploratory Analysis:* Calculated winning distributions, party performance, and candidate profiles.
* Data Visualizations:* Visualized winning trends, criminal record distribution, and winner age spreads using Seaborn.

# Tech Stack
* Language:* Python
* Libraries:* Pandas, Seaborn, Matplotlib, Regex

# Visualizations Included
1 Top 10 Parties by Seats Won* (Bar Chart)
2 Total Criminal Cases Reported by Major Parties* (Bar Chart)
3 Age Distribution: Winners vs Non-Winners* (Box Plot)
